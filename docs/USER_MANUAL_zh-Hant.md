# PondGate 使用手冊（v1.1.0）

> 本檔由 `docs/build_manual.js` 從 `dist/help-content.js` 產生，與軟體內「開始這裡 → 使用手冊」內容相同。

## 1. PondGate 能做什麼、不能做什麼

PondGate 計算**一座滯洪池**在**已知入流歷線**下的水位、蓄水量與出流隨時間的變化，並保留每次計算的可追溯紀錄。

- 計算方法：水平池（蓄水連續）方程 dS/dt = Qin − Qout(H)，以固定步長四階 Runge–Kutta（RK4，Δt = 2 秒）求解。
- 可以做：單池路由、讀取尖峰削減與滯洪量、在宣告的限制下做「受限設計篩選」與「連續最佳化」、下載紀錄、與 HEC-HMS／SWMM 輸出做數值比較。
- 不能做：降雨逕流計算、河道路由、長期連續模擬、多池串聯系統。
- 結果不是最終工程設計，也不是現地校準。與其他模式的一致只稱為「數值一致性」。工程責任仍由合格專業人員承擔。
- 沒有可行解時，系統會**阻擋**並顯示原因與修正方向，不會顯示「通過」。

## 2. 畫面導覽

- **左側選單**：「開始這裡」是本說明；「設定與路由」含模組 1–4；「受限設計篩選」是模組 5；「結果、驗證與紀錄」是模組 6；「教學與內部測試」有練習案例與自我檢核。
- **右上角**「English／中文」切換介面語言，輸入值不會改變。
- **左下角「？說明」**按鈕隨時打開 AI 助理與「下一步」提示。
- 欄位名稱旁的 **?** 可看該名詞的解釋。
- 每按一個按鈕，右下角會出現操作提示。

## 3. 五分鐘上手：用示範案例跑第一次

1. 打開頁面時已載入「三角形事件」示範案例，不代表您的工程資料。
2. 到「設定與路由」，捲到最下方，按**「執行路由與評估」**。
3. 系統自動切到「結果、驗證與紀錄」。先看結果表的「質量平衡殘差」是否接近 0 %，再看入流尖峰、出流尖峰與最高水位。
4. 想練習受限設計篩選：到「教學與內部測試」按「載入可執行受限篩選教學案例」，再到「受限設計篩選」按「執行受限設計篩選」。教學案例的自由出流勾選只是練習用的假設。
5. 按「下載可追溯決策支援報告」保存紀錄。

## 4. 模組 1：入流邊界

- **標準案例**：三角形事件、長延時事件或使用者自訂事件。
- **入流尖峰 Qp**（m³/s）必須大於 0。
- **入流形狀**：三角形用洪峰到達時間 Tp 與退水時間 Tr（或 Tp 與 Tp/Tr 比值）；長延時平頂用上升、平頂與退水時間。總事件延時 T 會自動計算，不能直接輸入。
- **匯入時間—流量對**：每行一組「時間（分鐘）, 流量（m³/s）」，第一行時間必須為 0，時間必須遞增，流量不可為負，至少兩行。例如：`0, 0`、`25, 0.10`、`50, 0.10`、`75, 0`。
- 只看尖峰流量不夠，歷線的延時與形狀也會改變需要的滯洪量。

## 5. 模組 2：蓄水量—水位狀態

- **固定平面面積**：S(H) = A ×（H − Hfloor），只需填平面面積 A（m²，必須大於 0）。
- **水位—蓄水量表**：可匯入 .csv 或 .txt，兩欄：第一欄水位（m），第二欄蓄水量（m³）。路由不會外插超出表格範圍。
- **池底高程 Hfloor**、**初始水位 H0**、所有出口高程必須用**同一個高程基準**。用相對基準時設 Hfloor = 0。H0 不可低於 Hfloor。

## 6. 模組 3：出口水理與自由出流證據

- **銳頂堰**：Qout = Cw × b ×（H − P）^1.5；需填堰流係數 Cw、堰寬 b、堰頂高程 P。
- **矩形開口**：Qout = Cd × Ao × √(2g（H − 開口底高程）)；需填 Cd、開口面積 Ao、開口底高程。
- **豎井、圓管、水位相關係數表、堰＋開口複合出口**屬「研究檢視」：可以路由看結果，但受限設計篩選會鎖定。
- 係數可選預設值（例如 Cw = 1.70、Cd = 0.62），或填現場校正值；預設值只適合初步篩選。
- **自由出流證據**：受限篩選前必須勾選「已確認自由出流邊界」及四項檢核（尾水、回水／管摩阻、淹沒、操作控制），並填寫兩項紀錄（自由出流證據紀錄、篩選限制依據）。**只有在您真的有圖說、現地檢查或計算依據時才勾選**；軟體不會替您驗證這些條件。

## 7. 模組 4：執行路由

- 按**「執行路由與評估」**開始計算，結果顯示在模組 6。
- 按鈕變**灰色**代表模組 1–3 有欄位不合理。按鈕上方會列出需要修正的欄位，點一下就會跳到該欄位（紅框標示）。
- 常見原因：Qp 小於或等於 0、平面面積為 0、堰寬或係數為 0、出口高程低於池底、沒有啟用任何出口。

## 8. 模組 6：讀懂結果

- **先看質量平衡殘差 ε/Vin**：應接近 0 %。超過 0.5 % 時系統會要求先解決數值問題。
- **出流尖峰 Qp,o** 與 **尖峰比 RQ**：RQ 越小，削峰越多。
- **事件新增滯洪量 ΔSmax** 與 **最高水位 Hmax**：與容許水位及出水高比較。
- **近洪峰平坦指標 FPI95**：數值大代表洪峰很平，單一「峰值時間」不可靠，應改用體積時間指標。
- 圖形：左圖為入流與出流歷線，右圖為水位與蓄水量。「展示時間」可調整橫軸長度。
- 「受限設計篩選與最佳化結果驗證」三步判讀只針對模組 5 的結果；只做一般路由時會顯示「尚未執行受限篩選」。

## 9. 模組 5：受限設計篩選與連續最佳化

- 開放條件：只啟用**單一銳頂堰**或**單一矩形開口**、固定係數、自由出流四項檢核與兩項紀錄完整。
- 先填**容許出流尖峰 Qallow**（m³/s）與**容許水位 Hallow**（m）。這兩個值應來自法規或設計準則，並寫進「篩選限制依據」。
- **最長排空時間 Td** 與**容許殘留百分比**：在 Te + Td 時，事件新增蓄水不得超過 ΔSmax 的該百分比。
- **參考水位 Href** 只用於無因次參數 ΠQ、ΠS，不自動等於安全限制。
- 篩選邊界：填堰寬 b 或開口面積 Ao 的最小、最大值；每個勾選尺寸在邊界內等距測試五個值。
- **連續最佳化**：在最小與最大平面面積之間，同時搜尋面積 A 與一個出口尺寸。結果不是已證明的全域最佳解。
- **無可行解**：系統顯示「阻擋」與主導限制（出流尖峰、最高水位或排空殘留），並提供「前往修正」。請依工程依據調整池面積或出口尺寸，**不要為了得到解而任意放寬 Qallow 或 Hallow**。

## 10. 下載報告與可追溯紀錄

- 模組 6 的「本次可追溯紀錄（唯讀）」列出本輪輸入、方法、結果與限制。
- 「下載可追溯決策支援報告」存成文字檔，包含輸入、結果與適用範圍，可附在設計紀錄中。
- 輸入改變後，舊結果會失效，請重新執行。

## 11. 與 HEC-HMS／SWMM 比較

- 在模組 6「外部模型交叉驗算」選參考歷線（目前路由結果或公開基準 A-005～D-005）與外部模型。
- 匯入外部模型的**實際模擬結果 CSV**。第一列為欄名；必要欄位為 time_s（或 time、t）與 outflow_m3_s（或 qout、qo）；完整比較另需 incremental_storage_m3（或 s、storage）。
- 外部模型必須使用相同的入流、初始水位、S(H)、Q(H)、係數與時間設定。比較結果只代表數值一致性，不是現地驗證。

## 12. 常見問題

- **按鈕是灰的？**看按鈕上方的紅色清單，點欄位名稱去修正。
- **受限篩選一直鎖定？**檢查是否只啟用一種出口、係數是否為固定值、自由出流四項檢核與兩項紀錄是否完整。
- **出現「無可行解」？**這是正常的阻擋，代表在目前邊界內沒有設計能同時符合限制。依「主導限制」調整面積或出口尺寸，或擴大有工程依據的搜尋邊界。
- **資料會上傳嗎？**不會。計算、說明與 AI 助理都在瀏覽器內執行，不會傳送資料。
- **結果可以直接當設計核准嗎？**不行。結果只在宣告的條件下成立，須由專業人員判斷。

## 名詞表

- **入流尖峰 Qp**（Peak inflow Qp）：入流歷線的最大流量（m³/s），必須大於 0。
- **洪峰到達時間 Tp**（Time to peak Tp）：三角形入流從 0 上升到尖峰所需的時間（分鐘）。
- **退水時間 Tr**（Recession time Tr）：三角形入流從尖峰下降到 0 所需的時間（分鐘）。
- **總事件延時 T**（Total event duration T）：入流歷線的總長度（分鐘），由各段時間自動相加，不能直接輸入。
- **蓄水量—水位關係 S(H)**（Stage–storage relation S(H)）：池中水位 H 與蓄水量 S 的對應關係。固定面積時 S = A ×（H − Hfloor）。
- **平面面積 A**（Plan area A）：固定面積模式下的池面積（m²），必須大於 0。
- **池底高程 Hfloor**（Floor elevation Hfloor）：池底的高程（m）。所有水位與出口高程都要與它使用同一個基準。
- **初始水位 H0**（Initial level H0）：事件開始時的池內水位（m），不可低於 Hfloor。
- **高程基準**（Vertical datum）：量測高程的共同零點。池底、水位、堰頂、開口底都要用同一個基準，否則結果錯誤。
- **堰流係數 Cw**（Weir coefficient Cw）：銳頂堰公式 Q = Cw × b ×（H − P）^1.5 中的係數。預設 1.70 只供初步篩選。
- **堰寬 b**（Weir width b）：銳頂堰的溢流寬度（m）。
- **堰頂高程 P**（Crest elevation P）：水位超過此高程才開始溢流（m）。
- **流量係數 Cd**（Discharge coefficient Cd）：矩形開口公式 Q = Cd × Ao × √(2g(H − 開口底高程)) 中的係數。預設 0.62。
- **開口面積 Ao**（Opening area Ao）：矩形開口的斷面積（m²）＝ 高度 a × 寬度 b。
- **開口底高程**（Invert elevation）：矩形開口的下緣高程（m），水位高於此值才出流。
- **研究檢視**（Research inspection）：豎井、圓管、係數表或複合出口的設定。可以路由看結果，但受限設計篩選鎖定，須另行獨立驗證。
- **自由出流**（Free discharge）：出口流量只由池內水位決定，不受尾水、下游回水、淹沒或閘門操作影響。受限篩選前必須有證據並勾選四項檢核。
- **兩項可追溯紀錄**（Two evidence records）：「自由出流證據紀錄」與「篩選限制依據」：寫明圖說或檢查編號、檢核人與日期，以及 Qallow、Hallow 等限制的來源。
- **RK4**（RK4）：四階 Runge–Kutta 法，用固定時間步長 Δt = 2 秒逐步解 dS/dt = Qin − Qout。
- **質量平衡殘差 ε/Vin**（Mass-balance residual ε/Vin）：累積淨入流與蓄水變化的差，除以入流總體積。應接近 0 %；超過 0.5 % 不可使用結果。
- **尖峰比 RQ**（Peak ratio RQ）：RQ = 出流尖峰 ÷ 入流尖峰。越小代表削峰越多。
- **事件新增滯洪量 ΔSmax**（Event-added detention ΔSmax）：事件期間相對初始蓄水量的最大新增蓄水（m³）。
- **蓄水比 RS**（Storage ratio RS）：RS = ΔSmax ÷ 入流總體積 Vin。
- **無因次遲滯 RT**（Dimensionless lag RT）：RT =（出流尖峰時間 − 入流尖峰時間）÷ 事件延時。
- **最高水位 Hmax**（Maximum level Hmax）：事件中池內最高水位（m），應與容許水位 Hallow 及出水高比較。
- **近洪峰平坦指標 FPI95**（Near-peak flatness FPI95）：出流在 95 % 尖峰以上的持續時間占路由時間的比例。數值大代表峰很平，單一峰值時間不可靠。
- **容許出流尖峰 Qallow**（Allowable peak outflow Qallow）：受限篩選中出流尖峰的上限（m³/s），應依法規或設計準則填寫。
- **容許水位 Hallow**（Allowable level Hallow）：受限篩選中最高水位的上限（m），不可低於 H0。
- **最長排空時間 Td 與殘留百分比**（Drain-down time Td and residual）：在事件結束時間 Te 再加 Td 時，事件新增蓄水不得超過 ΔSmax 的宣告百分比。
- **參考水位 Href**（Reference level Href）：只用來定義無因次參數 ΠQ、ΠS 的水位（m），不自動等於安全限制。
- **無因次參數 ΠH、ΠQ、ΠS**（Dimensionless groups ΠH, ΠQ, ΠS）：把水位、出流能力與庫容以入流尺度正規化的比值，用於比較不同案例；不是通用設計公式。
- **受限設計篩選**（Constrained screening）：在宣告的限制與搜尋邊界內，逐一重跑路由找出可行的池面積與出口尺寸。結果不是最終設計。
- **連續最佳化**（Continuous optimization）：在面積上下限之間連續搜尋面積 A 與一個出口尺寸，再局部精修；不是已證明的全域最佳解。
- **阻擋／無可行解**（Blocked / no feasible solution）：在目前的限制與邊界內，沒有任何候選能同時符合所有條件。系統顯示主導限制與修正方向，不會顯示「通過」。
- **數值一致性**（Numerical consistency）：用相同輸入與物理設定時，PondGate 與 HEC-HMS／SWMM 的計算結果相近。不代表現地校準或普遍驗證。
- **176 組回歸測試**（176-case regression）：用 176 組實驗室案例（352 條原始歷線）檢查每次發版的 RK4 核心結果不變；尖峰流量 MARE：A 2.924 %、B 2.954 %、C 4.104 %、D 4.649 %。
