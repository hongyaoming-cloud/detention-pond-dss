# 第一部　使用手冊

## 第 1 章　PondGate 能做什麼、不能做什麼

PondGate 是一套在瀏覽器中執行的滯洪池演算軟體。它計算一座滯洪池在已知入流歷線下，水位、蓄水量與出流隨時間的變化，並把每次計算的輸入、方法與結果保存成可追溯的紀錄。

### 1.1 計算方法一句話

軟體解的是水平池（蓄水連續）方程：

```formula
dS/dt = Qin(t) − Qout(H)
```

其中 S 是池內蓄水量，H 是水位，Qin 是入流，Qout 是出口流量。方程以固定步長的四階 Runge–Kutta 法（RK4，Δt = 2 秒）求解。原理與手算驗證放在第 11 至 13 章。

### 1.2 可以做的事

- 單一滯洪池的入流—出流路由，讀出尖峰削減、最高水位與事件新增滯洪量。
- 在宣告的容許出流與容許水位下，做「受限設計篩選」與「連續最佳化」，找出可行的池面積與出口尺寸。
- 下載包含輸入、結果與適用範圍的可追溯報告。
- 與 HEC-HMS、SWMM 的模擬結果做數值比較。
- 登入帳號後，把案例存成專案，並分享給同公司的同事（第 2 章）。

### 1.3 不能做的事

- 降雨逕流計算：入流歷線必須由使用者提供。
- 河道路由、長期連續模擬、多池串聯系統。
- 現地校準：與其他模式結果相近，只稱為「數值一致性」。
- 工程核准：結果不是最終設計，工程責任仍由合格專業人員承擔。

### 1.4 軟體不會替您說「通過」

當目前的限制與搜尋邊界內沒有任何可行設計時，PondGate 會「阻擋」，並列出主導限制與修正方向，而不會顯示「通過」。這個設計是刻意的：它避免使用者在證據不足時得到看似合格的結果。第 18 章用範例說明如何讀懂阻擋。

## 第 2 章　帳號、公司與專案

不登入也能使用全部計算功能。登入帳號的好處是可以把案例存成專案、下次接著做，並與同公司的同事分享。

### 2.1 四種權限

| 權限 | 可以做的事 | 不能做的事 |
| --- | --- | --- |
| 系統管理者 | 新增公司與各公司的帳號 | 打開公司的專案 |
| 公司管理者 | 管理自己公司的帳號，查看公司全部專案 | 管理其他公司 |
| 工程師 | 建立、儲存自己的專案，可分享給同事 | 修改同事的專案 |
| 檢視者 | 開啟同事分享的專案 | 存檔 |

系統管理者刻意不能打開公司專案，這樣公司的工程資料只留在公司內部。

### 2.2 第一次登入

1. 按畫面右上角的「登入」。
2. 輸入管理者發給您的帳號與初始密碼。
3. 系統會要求您立即改成自己的密碼。新密碼至少 8 個字元，要輸入兩次。
4. 忘記密碼時，請洽貴公司的管理者幫您重設；系統不寄送密碼。

### 2.3 建立帳號的順序

1. 系統管理者先新增公司。
2. 系統管理者替這家公司建立一個「公司管理者」帳號。
3. 公司管理者登入後，自己建立工程師與檢視者帳號。

建立帳號時可以按「產生隨機密碼」，再把密碼私下交給同事。

### 2.4 儲存與開啟專案

- 工程師與公司管理者可以按「存檔／開啟專案」，把目前畫面上的所有輸入存成新專案，並填寫名稱與備註。
- 勾選「分享給同公司的人」後，同事可以開啟，但只能看，不能改。
- 畫面上方會顯示目前專案名稱。出現「● 有未儲存的變更」時，記得按「儲存」。
- 開啟專案後，結果不會自動出現。請到模組 4 按「執行」重新計算。這樣可以確保結果一定是用目前版本的軟體算出來的。

### 2.5 回收區與操作紀錄

- 刪除專案時，專案只會移到回收區，不會真的消失；在回收區按「還原」就能找回。
- 公司管理者可以在「帳號管理」查看最近 300 筆操作紀錄，例如誰在什麼時候建立、分享或刪除了哪個專案。

### 2.6 資料存在哪裡

不登入時，計算全部在您的瀏覽器內完成，不傳送任何資料。登入並存檔時，專案的輸入值會存放在 PondGate 的雲端資料庫（Cloudflare）。密碼只以加密雜湊保存，任何人（包括系統管理者）都看不到您的密碼。

## 第 3 章　畫面導覽

![PondGate 的畫面配置](manual/guide/g02_01_layout.png)

圖 3-1 顯示 PondGate 的四個主要區域。

1. 頁籤列：「開始這裡」、「設定與路由」、「受限設計篩選」、「結果、驗證與紀錄」、「教學與內部測試」。
2. 語言切換：按鈕寫「English」表示目前是中文介面。
3. 「？說明／AI 助理」按鈕，隨時可以按。
4. 工作區：目前頁面的內容。

### 3.1 「開始這裡」說明中心

![「開始這裡」頁](manual/guide/g02_02_start.png)

圖 3-2 是「開始這裡」頁。上方分頁依序是：開始這裡、引導練習、使用手冊、完整版操作手冊、工具書（本書）、名詞表與 AI 助理。

- 「下一步」方框會隨您的操作改變，告訴您現在該做什麼。
- 「引導練習」有 7 個由淺入深的練習，每一步完成後系統會自動打勾。
- 欄位名稱旁的「?」可以看該名詞的解釋。

### 3.2 小提示

- 每按一個按鈕，右下角會出現操作提示，說明剛才發生了什麼。
- 切換語言不會改變輸入值。若輸入在上次計算後改過，切換語言會依目前輸入重新計算一次，畫面會先提醒您。
- 手機也能使用，頁籤列會移到畫面上方。
