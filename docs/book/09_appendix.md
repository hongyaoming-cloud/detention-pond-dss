## 附錄 B　錯誤訊息與處理方式

| 畫面訊息或狀況 | 意思 | 處理方式 |
| --- | --- | --- |
| 執行按鈕呈灰色，上方有紅色清單 | 有欄位不合理 | 點清單中的欄位名稱，修正紅框欄位 |
| 「受限篩選尚未執行」 | 只做了一般路由 | 一般路由請看「新手判讀」；要篩選請到模組 5 |
| 模組 5 列出缺少的條件 | 受限篩選的開放條件不足 | 依清單中「要查」與「要填」補齊 |
| 「阻擋：…找不到可行篩選案例」 | 邊界內無可行設計 | 依主導限制調整，見第 18 章 |
| 結果被標示為過期 | 計算後輸入已改變 | 重新按「執行」 |
| 質量平衡殘差超過 0.5 % | 數值問題 | 檢查單位、高程基準與水位—蓄水量表範圍 |
| 匯入時間—流量對失敗 | 格式錯誤 | 第一行時間為 0、時間遞增、流量不為負、至少兩行 |
| 開啟專案後沒有結果 | 專案只存輸入 | 到模組 4 按「執行」 |
| 檢視者無法存檔 | 權限設定 | 請公司管理者調整權限，或請工程師存檔 |
