# PondGate Detention-Pond Routing in Practice — User Manual and Worked Examples

## Preface

This book is the handbook of PondGate. It has two parts.

Part I is the user manual. It follows the order of the software screens and explains what to enter, what to press and what to read in each module. First-time users can start with Chapter 4, "Five-minute start", and look up the other chapters when needed.

Part II is a set of worked examples. It starts from the hydraulic principles of detention ponds. It then uses the public benchmark cases built into the software to work step by step through routing, interpretation, design screening and cross-checks with external models. Each chapter has four parts: principle, step-by-step example, check and exercises. Answers to the exercises are in Appendix C.

### Scope of this book

PondGate computes the water level, storage and outflow of one detention pond under a known inflow hydrograph. It does not compute rainfall–runoff, channel routing, long-term continuous simulation or ponds in series.

Every result in this book holds only under the declared inputs and assumptions. Neither the software nor this book replaces design codes, site investigation or the judgement of a professional engineer. Every tick and record marked "teaching assumption" is for practice only and must not be used in real projects.

### Where the numbers come from

Every result number in Part II was read from this version of the software after a real run. An independent small program then recomputed it for checking. If you get a different number with the same software version, first check that your inputs are exactly the same as in the book.

### Version and citation

This English edition matches PondGate v1.3.4. The screenshots were taken in the English interface. The source code is public on GitHub (hongyaoming-cloud/detention-pond-dss), and the Zenodo DOIs of each version are listed in Appendix D.
